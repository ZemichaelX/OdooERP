# SapianERP — navigation chrome specification (moved)

**This specification is no longer kept in the public repository.** It lives in
the private `sapianerp-internal` repository, under the same path.

It was moved on 18 August 2026, a few hours after the repository was opened. An
earlier pass had already taken out the competitor's name, their hostname, the
"measured from their running system" provenance and the demo credentials printed
on their login page. What was left still read as a teardown of an identifiable
third-party system — some forty lines of *theirs* and measured values — and an
anonymised teardown is still a teardown. Scrubbing it further would have left a
specification that no longer said anything.

None of it is secret and none of it was obtained improperly: it is what any
visitor sees in a browser. It is simply not ours to publish.

What shipped from it is public and stays public — the app rail, the labelled
sidebar, the launcher, the footer, and the auth pages, in `addons/sapian_theme`
and `addons/sapian_theme_website`, each with its own README and tests. The
implementations are the useful part; the survey behind them is not.

Ask the owner for access if you need the specification itself.
